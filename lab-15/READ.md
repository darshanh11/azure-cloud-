# Azure Projects

Hands-on Azure labs demonstrating practical experience with cloud infrastructure, networking, virtual machines, identity, storage, monitoring, security, and Infrastructure as Code.

## Cloud Infrastructure Deployment

Configured and managed Azure cloud resources through the Azure Portal, including virtual machines, storage resources, networking components, and related cloud services.

## Azure Networking

Practiced Azure networking concepts including Virtual Networks (VNet), subnets, IP addressing, Network Security Groups (NSG), Azure Firewall, and network configuration.

## Virtual Machines

Created and configured Azure Virtual Machines by selecting operating system images, VM sizes, disks, networking settings, administrator credentials, and inbound access settings.

## Identity and Access Management

Worked with Azure identity and access concepts including Microsoft Entra ID, authentication, authorization, and role-based access control (RBAC).

## Azure Storage

Practiced Azure Storage services including Storage Accounts, Blob Storage, Azure Files, Queue Storage, Table Storage, storage tiers, redundancy, and storage security.

## Azure Monitoring

Explored Azure monitoring and management services including Azure Monitor, Log Analytics, alerts, Activity Log, Azure Service Health, and Azure Advisor.

## Infrastructure as Code

Practiced Infrastructure as Code concepts using ARM Templates, Bicep, and Terraform for defining and deploying Azure infrastructure.
