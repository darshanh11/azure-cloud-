# Cloud Computing Fundamentals

## 1. What is Cloud Computing?

Cloud computing is the delivery of computing resources such as servers, storage, databases, networking, software, and applications over the internet on demand.

Instead of purchasing and maintaining physical hardware in a data center, organizations can use cloud resources from a cloud service provider.

### Examples

- Virtual Machines
- Cloud Storage
- Databases
- Virtual Networks
- Applications

### Cloud Service Providers

- Microsoft Azure
- Amazon Web Services (AWS)
- Google Cloud Platform (GCP)

### Advantages

- Reduced infrastructure cost
- Scalability
- High availability
- Flexibility
- Faster deployment
- Global accessibility

---

## 2. Benefits of Cloud Computing

- **Cost Savings** — No need to purchase and maintain large amounts of physical hardware.
- **Scalability** — Increase or decrease resources based on workload.
- **Elasticity** — Resources can automatically adjust to changing demand.
- **High Availability** — Applications can remain available even when some resources fail.
- **Fault Tolerance** — Systems can continue operating despite hardware or component failures.
- **Global Reach** — Deploy applications and services closer to users around the world.
- **Flexibility** — Quickly provision the resources you need.
- **Faster Deployment** — Create infrastructure and services much faster than traditional data centers.
- **Disaster Recovery** — Replicate and recover data and workloads when failures occur.
- **Security** — Cloud providers offer security services and tools to help protect workloads.
- **Automatic Updates** — Many managed services reduce the need for manual maintenance.
- **Pay-as-you-go** — Generally pay for the resources and services you consume rather than buying everything upfront.
- **Performance** — Access scalable computing resources when higher workloads require them.
- **Backup and Data Protection** — Cloud services can provide backup, replication, and redundancy options.

## 3. On-Premises vs Cloud

| Feature | On-Premises | Cloud |
|---|---|---|
| Hardware | Owned by organization | Provided by cloud provider |
| Initial Cost | High | Usually lower upfront |
| Maintenance | Organization | Mostly provider |
| Scalability | Limited / slower | Fast and flexible |
| Deployment | Takes longer | Usually much faster |
| Location | Own data center | Provider's data centers |
| Availability | Organization manages it | Cloud offers HA options |
| Payment | Hardware investment | Usage / service-based |
| Upgrades | Organization manages | Provider manages infrastructure |
| Global Deployment | More difficult | Easier across regions |

### Advantages of On-Premises

- Full control over infrastructure
- Greater control over physical hardware
- Useful for specific compliance or legacy requirements
- Can operate independently of internet connectivity for some workloads

### Advantages of Cloud

- Lower upfront infrastructure investment
- Rapid deployment
- Easy scalability
- Global reach
- High availability options
- Managed services
- Flexible resource usage

### Example

**On-Premises:** A company purchases physical servers and installs them in its own data center.

**Azure:** The company creates an Azure Virtual Machine and uses Azure's underlying infrastructure instead of purchasing and maintaining the physical server itself.

## 4. Cloud Service Providers (CSPs)

Cloud Service Providers (CSPs) are companies that provide computing resources and services over the internet. These services can include computing, storage, networking, databases, security, and other IT resources.

Instead of purchasing and maintaining physical infrastructure, organizations can use resources provided by a CSP according to their requirements.

### Major Cloud Service Providers

#### 1. Microsoft Azure

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, networking, storage, databases, security, identity, monitoring, and many other workloads.

**Examples:**

- Azure Virtual Machines
- Azure Virtual Network

#### 2. Amazon Web Services (AWS)

Amazon Web Services (AWS) is Amazon's cloud computing platform. It provides services for computing, storage, networking, databases, security, and other cloud workloads.

**Examples:**

- Amazon EC2
- Amazon S3

#### 3. Google Cloud

Google Cloud is Google's cloud computing platform. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, and machine learning.

**Examples:**

- Compute Engine
- Cloud Storage

## 5. Microsoft Azure Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides a wide range of cloud services that organizations and individuals can use to build, deploy, manage, and run applications and infrastructure over the internet.

Azure provides services for computing, networking, storage, databases, security, identity, monitoring, artificial intelligence, and automation.

### Key Azure Services

#### 1. Compute

Azure provides computing services that allow users to run applications and workloads without maintaining physical servers.

**Examples:**

- Azure Virtual Machines
- Azure App Service

#### 2. Networking

Azure provides networking services for connecting and securing applications, virtual machines, and other resources.

**Examples:**

- Azure Virtual Network (VNet)
- Network Security Group (NSG)

#### 3. Storage

Azure provides different types of storage for storing files, application data, backups, and other information.

**Example:**

- Azure Blob Storage

#### 4. Identity and Access Management

Microsoft Entra ID is Azure's cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to resources.

**Examples:**

- Microsoft Entra ID
- Azure Role-Based Access Control (RBAC)

#### 5. Security and Monitoring

Azure provides services for protecting resources and monitoring the health and performance of applications and infrastructure.

**Examples:**

- Microsoft Defender for Cloud
- Azure Monitor

#### 6. Management and Automation

Azure provides tools that help users create, manage, and automate cloud resources.

**Examples:**

- Azure Portal
- Azure CLI
